# VE Miner & Badges

VELOOP Rewards – UI/UX Design Internship Task Assignment

Task 11 – Mining Banner s 10-Level Achievement Badge Design

Task Type: UI/UX Design – Figma

1. Project Overview

For this assignment, you are required to design two connected visual experiences for

VELOOP Rewards:

Part A — Mining Banner

A premium, interactive banner/card for the Mine s Earn section.

Part B — Achievement Badge System

A complete set of 10 achievement badges that users can unlock progressively as they

engage with the platform.

The objective is to create visuals that don't just look attractive but also encourage users

to return to VELOOP Rewards, progress through levels, and feel rewarded for their

activity.

This task is focused on UI/UX and visual design only.

The final designs must be created in Figma.

2. Design Goal

The overall experience should feel:

 Premium

 Modern

 Gamified

 Trustworthy

 Reward-focused

 Motivating

 Interactive

 Fintech-inspired

 Achievement-oriented

 Professional

The gamification should be sophisticated.

It should feel like:

A premium rewards platform with gamified progression

and not like a childish mobile game.

3. Important Global Design Standards

#161827
